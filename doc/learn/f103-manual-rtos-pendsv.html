PendSV_Handler 逐条指令

调度器单步 时间片与双栈 原理

进入本段之前，硬件已经把 R0–R3、R12、LR、PC、xPSR 压进 key 的 PSP。下面只补 R4–R11，再换成 usart。

地址是示意。key 的硬件帧在 0x20000FE0。usart 的 sp 指着它栈帧里的 R4：0x20001400。

PUSH / POP 是对当前活动 SP 做 STMDB / LDMIA 的别名。Handler 里活动 SP 是 MSP，所以 R4–R11 必须写明 PSP，不能 PUSH {R4-R11}。

Cortex-M3 可以一条指令带走 R8–R11。Cortex-M0 的多寄存器存取只能直接带 R0–R7，高寄存器要先搬到低寄存器。

FreeRTOS 的 GCC ARM_CM3 端口在 BL vTaskSwitchContext 前后写 BASEPRI，并在 MSP 上保存 R3 和 R14。本工程的 PendSV 只 PUSH {LR}，不写 BASEPRI。临界区在 os.c 里用 PRIMASK。

  1. 先看 MRS R0, PSP：要操作的是任务栈，不是 MSP。
  2. 再看 STMDB：减 32 字节，R4 在最低地址。
  3. STR R0, [R2] 把进度写入当前 TCB。
  4. LDR R0, [R0] 取出下一个任务的 sp。
  5. MSR PSP, R0 和 BX LR 之后，硬件才从新 PSP 恢复剩下的 8 个字。
