# GPIO 保护二极管与负压

整理自学习笔记（两份合并去重），说明 **VSS/VDD 电位参考**、GPIO **钳位保护结构**、引脚为何会出现 **低于地电位的负压**，以及 STM32F103 上 **TT/FT 引脚** 与通用「上下一对二极管」模型的差异。绝对最大值以 [DS5319](../reference/stm32f103/md/datasheet-index.md) 为准；GPIO 模式见 [gpio-eight-modes.md](gpio-eight-modes.md)。

---

## 一句话总结

**负压 = GPIO 引脚电位低于本板地线（VSS）的电位。** 地线本身不变；外部电感、地差、静电等可把引脚「拉到地下面」。一旦低于约 VSS，下端保护结构导通泄放；过大能量仍需外部 TVS。STM32 的 **5 V 容忍（FT）脚没有接到 VDD 的上钳位二极管**，勿把通用双二极管模型套到所有脚。

---

## 1. 先搞清楚 VSS 是什么

在单片机原理图里：

| 符号 | 含义 |
|------|------|
| **VSS** | 电源地（GND），标称电位 **0 V**（本板测量基准） |
| **VDD** | 电源正极，F103 核心板常见 **3.3 V** |

理想情况下 VSS 是 0 V，但 **电压是相对的**：引脚电位可以比 VSS（地）更低，也就是负压。

> ✅ **小于 VSS** = 引脚电压 ＜ 0 V（相对本板地为负）

### 核心概念

**VSS = 本电路板的地线，人为规定它电位 = 0 V。它只是测量基准，不是电压下限。**

电压本质是 **两点电位之差**，不是绝对数值。

> 「引脚电压 ＜ VSS」意思：**GPIO 引脚电位比这块板的地线电位还要低**，相对于本地 GND 出现负压。

举个类比：把海平面定为 0 米（相当于 VSS = 0 V）。海平面是基准，但可以有海底，海拔 −10 米，比海平面更低。**负压就相当于电位掉到了「海平面之下」。** 电路板地线是海平面，负压是引脚瞬间沉到海平面下面。

### 容易踩坑

| 误区 | 纠正 |
|------|------|
| ❌ VSS 是地，电压最低，不可能有比它更小的电压 | ✅ VSS 是 **电位参考点**，不是电路最低电位；干扰尖峰可以瞬时产生低于地电位的负压 |
| ❌ 负压就是地线变成负电压 | ✅ 地线电位不变，是 **引脚电位** 下降到地线电位之下 |
| ❌ 只要出现一点点负压芯片立刻烧毁 | ✅ 短时间、幅度不大的负尖峰可由内部保护泄放；很大、很长仍会烧 IO，需外部 TVS |

## 2. GPIO 保护结构（通用模型 vs STM32）

### 2.1 教科书「上下一对钳位二极管」（通用 CMOS 模型）

许多教材画的典型保护电路：

1. **上保护二极管**：阳极接 GPIO，阴极接 VDD  
   - 当引脚电压 ＞ VDD，二极管导通，把电压钳位到约 VDD + 0.7 V，防止过高正电压击穿 IO。
2. **下保护二极管**：阳极接 VSS(0 V)，阴极接 GPIO 引脚  

```text
VSS(0V) ──▶|── GPIO引脚
         二极管（阳极 VSS，阴极 IO）
```

二极管导通条件：**阳极电压 ＞ 阴极电压，压差 ≥ 正向压降（≈ 0.7 V）**。

| 情况 | 行为 |
|------|------|
| 正常：IO = 0～3.3 V | 阴极电位 ≥ 阳极（0 V），下二极管 **截止** |
| IO 出现负压：引脚 ＜ 0 V | 阳极(0 V) ＞ 阴极（负压）→ 下端二极管 **导通** |

导通后负压被钳位在大约 **−0.7 V**（硅管正向压降的直觉值），防止负压继续加深。

一句话：

- IO 电压 ＞ VDD → 接 VDD 的上二极管导通（正向过压保护）
- **IO 电压 ＜ VSS（负压）→ 接 VSS 的下二极管导通（负向浪涌保护）**

### 2.2 负压时电流方向

负压到来瞬间（例：GPIO 变成 −1 V 相对 VSS）：

- 阳极 0 V，阴极 −1 V → 阳极比阴极高 1 V ＞ 0.7 V，二极管导通
- 电流路径：**VSS（地）→ 二极管阳极 → 阴极 → GPIO 引脚 → 外部干扰源**

> 电流不是从高电位流向低电位吗？是的：0 V 比 −1 V 电位更高，电流从地流向引脚，这就是负压触发保护的电流方向。

### 2.3 STM32F103：TT/TC 与 FT（官方纠正）

笔记里的「上下一对二极管」是 **通用模型**。STM32 引脚分两类（见 DS5319 引脚表 / 电气特性）：

| 类型 | 含义 | 上侧钳位 |
|------|------|----------|
| **TT / TC** | 标准 3.3 V I/O | 通常有接到 VDD（或类似）的保护结构；输入不宜长期超过 VDD |
| **FT（Five-volt Tolerant）** | 5 V 容忍输入 | **没有接到芯片 VDD 的上钳位二极管**，否则 5 V 会灌进电源轨 |

FT 脚上侧是内部 ESD / `VDD_FT` 一类结构（见 ST AN4899、RM0008 I/O 结构图、ST Community 说明），不是简单的「二极管接 VDD」。

绝对最大值（量级，以本地 DS5319 电气章节为准）：

| 类别 | 典型限制 |
|------|----------|
| 普通 / TT 类输入 | 约 **VSS − 0.3 V** ～ **VDD + 0.3 V** |
| FT 输入 | 可到约 **5.5 V**，但仍有 **VDD + 4 V** 一类上限 |
| 未上电 | **不要**往 FT 脚灌 5 V（VDD = 0 时头寸变差，可能损坏） |

钳位后约 −0.7 V 是硅管正向压降的 **直觉值**；手册额定负向多为 **VSS − 0.3 V**。超过额定会注入电流，内部保护扛不住仍会坏 IO。

### 2.4 与本仓库硬件

| 引脚 / 外设 | 注意 |
|-------------|------|
| PC13 LED | Backup / 振荡器相关，按 **3.3 V** 脚对待；勿接 5 V |
| USART1 PA9/PA10、SPI1 等 | 多为 **FT**；本仓库外设仍统一 **3.3 V** 供电 |
| 模块 VCC | 一律 3.3 V，勿接 5 V（见 [stm32f103-peripherals.md](../hardware/stm32f103-peripherals.md)） |

短尖峰可由内部结构泄放；大能量、长时负压或过压 → 外部 **TVS** / 串联电阻限流。

## 3. 负压到底是怎么产生的？

地线本身永远是本地 0 V，**负压不是地线变负，是外部信号把引脚瞬间拉到比地线更低**。

### 场景 1：电感断电反向电动势（最经典）

GPIO 驱动继电器线圈。线圈是电感。

- GPIO 输出高，有电流流过线圈
- GPIO 突然关闭，电感 **不想电流瞬间消失**，会强行产生感应电压维持电流
- 电感两端产生反向尖峰，一端接地，另一端接到 GPIO，一瞬间把 GPIO 拉到 **负电压**

简单理解：电感断电瞬间「使劲拽」GPIO 引脚，把它拽到地电位下面。

### 场景 2：两块电路板地线电位不一样（地漂移）

板子 A 和板子 B 通过信号线相连，但两根地线之间存在压差。

假设本板 VSS = 0 V，B 板地线电位是 +0.8 V。B 板输出「0 V」信号是相对于 B 自己的地；换算到本板参考点，这条信号线电压 = **−0.8 V**，对本板 GPIO 来说就是负压。

👉 两块地没有等电位，跨板通信极易出现负压。本仓库要求 **蓝板 / 面包板 / ST-Link / CH341 的 GND 连通**（ST-Link GND 同时接蓝板与面包板），即是为降低此类风险。见 [供电与共地](../hardware/power-and-common-ground.md)。

### 场景 3：静电 / 耦合干扰（瞬时尖峰）

长信号线、靠近开关走线，寄生电容耦合，静电放电。静电脉冲是短暂的电荷冲击，可以瞬间把引脚电荷抽走，电位短暂掉到 0 V 以下。这种负压持续时间极短，是尖峰脉冲。

### 直流负压 vs 负尖峰

| 类型 | 说明 |
|------|------|
| **直流负压** | 信号稳定长期为负（少见） |
| **负尖峰电压** | 平时正常 0～3.3 V，一瞬间短暂跌到负值（单片机 IO 损坏最常见元凶） |

用波形直观想象：正常 IO 在 0 V ↔ 3.3 V；来了负干扰尖峰，从 0 V 向下扎，短暂跌到 −1.5 V，马上回到 0 V。这个向下扎进 0 V 以下的脉冲，就是负压。一旦跌到低于 0 V，下端保护立刻导通，把它拉住，不让它继续往下掉（能量过大时仍可能损坏）。

---

## 4. 极简总结

负压 = **GPIO 引脚电位低于本板地线（VSS）的电位**。

地线本身不变，是外部电感、地差、静电干扰，短暂把引脚「拉到地下面」；一旦掉到 0 V 以下，连接 VSS 的保护结构正向导通，泄放干扰，钳位负压。

通用模型：过压靠上二极管、负压靠下二极管。STM32 **FT 脚没有简单的 VDD 上二极管**——查 DS5319 引脚类型，外设统一 3.3 V，大浪涌加外部保护。
