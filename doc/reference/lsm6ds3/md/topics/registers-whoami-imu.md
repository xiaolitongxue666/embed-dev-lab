## WHO_AM_I (0Fh)

§9.11（PDF p.53）：只读，固定值 **`69h`**。

| 地址 | 期望值 | 用途 |
|------|--------|------|
| `0x0F` | `0x69` | SPI 连通性与器件识别 |

若读到 `0x00`/`0xFF`：查 CS、供电、MISO=SAO。若读到 `0x6A`：模块可能是 **LSM6DS3TR-C**，勿用本手册期望 ID。

## CTRL1_XL (10h) — 加速度计

§9.12（PDF p.53–54）：

| 位域 | 含义 |
|------|------|
| `ODR_XL[3:0]` | 输出数据率与功耗相关选择 |
| `FS_XL[1:0]` | 满量程：`00`=±2 g，`01`=±16 g，`10`=±4 g，`11`=±8 g |
| `BW_XL[1:0]` | 抗混叠滤波带宽（与高性能模式等相关） |

本 demo 首版：`CTRL1_XL = 0x40` → `ODR_XL=0100`（**104 Hz**），`FS_XL=00`（**±2 g**）。

## CTRL2_G (11h) — 陀螺仪

§9.13（PDF p.55）：

| 位域 | 含义 |
|------|------|
| `ODR_G[3:0]` | 陀螺仪 ODR |
| `FS_G[1:0]` | 满量程：`00`=250 dps，`01`=500，`10`=1000，`11`=2000 |
| `FS_125` | 置 1 时选 125 dps |

本 demo 首版：`CTRL2_G = 0x40` → `ODR_G=0100`（**104 Hz**），`FS_G=00`（**250 dps**）。（Rev 8 文中亦见 ±245 dps 表述；控制位表按 250 dps 档。）

## STATUS_REG (1Eh)

§9.26（PDF p.63）：

| 位 | 名称 | 含义（1=有新数据） |
|----|------|-------------------|
| 0 | `XLDA` | 加速度计新数据 |
| 1 | `GDA` | 陀螺仪新数据 |
| 2 | `TDA` | 温度新数据 |
| 3 | `EV_BOOT` | boot 相关事件 |

轮询策略：读 STATUS；若 `XLDA` 或 `GDA` 置位，再连读输出寄存器。

## 输出寄存器（连读 12 字节）

从 `OUTX_L_G (22h)` 起（PDF p.64–66），`IF_INC=1` 时地址自增：

| 地址 | 名称 | 内容 |
|------|------|------|
| `0x22` | `OUTX_L_G` | 陀螺仪 X LSB |
| `0x23` | `OUTX_H_G` | 陀螺仪 X MSB |
| `0x24` | `OUTY_L_G` | 陀螺仪 Y LSB |
| `0x25` | `OUTY_H_G` | 陀螺仪 Y MSB |
| `0x26` | `OUTZ_L_G` | 陀螺仪 Z LSB |
| `0x27` | `OUTZ_H_G` | 陀螺仪 Z MSB |
| `0x28` | `OUTX_L_XL` | 加速度 X LSB |
| `0x29` | `OUTX_H_XL` | 加速度 X MSB |
| `0x2A` | `OUTY_L_XL` | 加速度 Y LSB |
| `0x2B` | `OUTY_H_XL` | 加速度 Y MSB |
| `0x2C` | `OUTZ_L_XL` | 加速度 Z LSB |
| `0x2D` | `OUTZ_H_XL` | 加速度 Z MSB |

值为 **二进制补码**；默认 LSB 在低地址（`CTRL3_C.BLE=0`）。

拼装：`raw = (int16_t)((msb << 8) | lsb)`。

## 灵敏度（换算用，demo 先打 raw）

Table 3 机械特性（PDF p.20–21）典型值：

| 量程 | 灵敏度 | 单位 |
|------|--------|------|
| 加速度 ±2 g | **0.061** | mg/LSB |
| 角速率 ±250 / ±245 dps 档 | **8.75** | mdps/LSB |

静止时某一轴约 1 g → raw 约 ±16384 LSB（@ ±2 g）。
